VACP Example: Vega-Lite spec gallery + @vacp/vega-lite

Pick a spec and VACP will expose Vega-Lite params as nodes/actions at window.__vacp. Enable the rendered overlay with ?vacpDebug=1.

What to try
  • Open the overlay: add ?vacpDebug=1, click the floating VACP button.
  • In the overlay, go to Demo and click Run all to replay param updates.
  • Move the slider (human interaction) and watch State update (signal-driven).
  • Use Actions to call vega_lite.set_param / vega_lite.clear_selection.
  • Use JSON → Apply state to live app to apply an edited state map (dev-only, best-effort).
