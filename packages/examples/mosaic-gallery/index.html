VACP Example: Mosaic spec gallery + @vacp/mosaic

Pick a spec and VACP will attach to the generated plot, exposing a bridge at window.__vacp. Enable the rendered overlay with ?vacpDebug=1.

What to try
  • Open the overlay: add ?vacpDebug=1, click the floating VACP button.
  • In the overlay, go to Demo and click Run all to replay a scripted selection sequence (agent-like interaction).
  • Brush on the chart with your mouse (human interaction) and watch State and history update.
  • Use Actions to dispatch the same semantic operations manually (no pixel automation).
  • Use JSON → Apply state to live app to apply an edited state map (dev-only, best-effort).
