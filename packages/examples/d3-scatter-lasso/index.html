VACP Example: Frameworkless D3 scatter + lasso

This is a vanilla (no framework) visualization that still exposes a VACP bridge at window.__vacp. Lasso with the mouse; then compare with the programmatic action dispatch. Enable the overlay with ?vacpDebug=1.

What to try
  • Open the overlay: add ?vacpDebug=1, click the floating VACP button.
  • In the overlay, go to Demo and click Run all to replay lasso actions.
  • Draw a lasso polygon with the mouse (human interaction) and watch Selected and state update.
  • Use Actions to call vanilla.set_lasso_polygon / vanilla.clear_lasso.
  • Use JSON → Apply state to live app to apply an edited polygon (dev-only, best-effort).
